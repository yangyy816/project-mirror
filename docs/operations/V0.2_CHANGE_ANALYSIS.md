## Migration decision

`0001_phase0_foundation` 在 v0.2 到达前刚由当前任务生成，尚未提交、分享、执行或由 PostgreSQL 验收，没有外部依赖者。依据 v0.2 §63，本次在首次权威验证前重生成该初始 migration，以避免把已废弃 placeholder 固化后再制造无意义增量。此例外只适用于尚未共享的初始 migration；后续 migration history 只前向追加。
